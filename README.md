## 🚀 Featured Projects

### 💬 WhatsApp Ordering Assistant
An LLM-powered ordering assistant that is live on the WhatsApp Cloud API.
- LangChain tool-calling agents with Groq/Gemini model fallback and a Supabase (PostgreSQL) database
- Deployed to **Azure App Service** with **GitHub Actions** CI/CD and HMAC-verified webhooks
- Human-in-the-loop approval buttons for staff and cost-aware notification design

### 🧠 CV Screening Pipeline
An LLM-powered candidate screening system built with **LangGraph**. Parses a job description into weighted requirements and matches each candidate against them with evidence-backed verdicts.
- Three-tier shortlist outcome (Shortlisted / Needs Review / Not Shortlisted) that routes borderline cases to human review instead of a hard cutoff
- Orchestrates multiple LLM providers in one pipeline (Groq for JD parsing, Gemini for CV matching)
- Ships as both a CLI tool and a Streamlit app, with PDF/DOCX ingestion
- 🔗 [Repo](https://github.com/Farhad-ALi-Farhat/cv-screening)

### 🕵️ DeepFake Detection & Awareness Platform
A deep learning platform for image and video deepfake detection (final year project).

- FastAPI inference backend integrated with React and Laravel front ends for uploads, inference, and result visualization
