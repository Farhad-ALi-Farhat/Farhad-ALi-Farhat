## 🚀 Featured Projects

### 🧠 CV Screening Pipeline
An LLM-powered candidate screening system built with **LangGraph**. Parses a job description into dynamically-derived, weighted requirements and matches each candidate against them with evidence-backed verdicts.
- Weighted scoring model with a three-tier shortlist outcome (Shortlisted / Needs Review / Not Shortlisted) — routes borderline cases to human review instead of a hard cutoff
- Orchestrates multiple LLM providers in one pipeline (Groq for JD parsing, Gemini for CV matching)
- Ships as both a CLI tool and a Streamlit app, with PDF/DOCX ingestion
- 🔗 [Repo](https://github.com/Farhad-ALi-Farhat/cv-screening)

### 🕵️ DeepFake Detection & Awareness Platform
A deep learning platform for image and video deepfake detection.
- CNN-LSTM architecture with transfer learning for classification
- Explainable AI via **LIME** to visualize model predictions and improve transparency
- FastAPI backend integrated with React and Laravel front ends for uploads, inference, and result visualization

### 🔍 XAI API
A FastAPI-based system for explaining deep learning model predictions.
- Uses **LIME** for model interpretability
- Exposes explanation results via a clean REST API
